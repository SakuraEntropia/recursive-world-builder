# 因果缺口怎么判

## 三步

1. **有没有规则覆盖？**
   `world.rules_for(subj_tags, verb, obj_tags)` 返回空 → `undefined_interaction`

2. **覆盖了，但两条打架？**
   同 verb、scope 有交集、effect 不同 → `contradiction`

3. **覆盖了，但看着怪？**
   → `counter_intuitive`，**记录，不修**

## 为什么第三类不修

**虚构世界允许违反现实常识。**

**重力可以反，时间可以分层，人可以造。**

**只有「内部矛盾」和「没有定义」才是缺陷。**

## 判缺口时的三个问题

**一、这是不是我已经知道、只是没写进 `world.json` 的设定？**
→ 是的话，补进数据，不算缺口。

**二、这是不是作者故意留白？**
→ 是的话，标记为「留白」，不算缺口。

**三、补上它，会不会把作品的怪味磨平？**
→ 会的话，先问作者。
